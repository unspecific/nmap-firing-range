■ Connection Instructions

Windows

  1. Open Settings → Network & Internet → VPN
  2. Click Add a VPN connection
  3. VPN provider: Windows (built-in)
  4. Connection name: NFR Lab
  5. Server name or address: —
  6. VPN type: L2TP/IPsec with pre-shared key
  7. Pre-shared key: —
  8. Username / Password: as shown above
  9. Save, then click Connect

macOS

  1. Open System Settings → VPN
  2. Click Add VPN Configuration → L2TP over IPSec
  3. Display name: NFR Lab
  4. Server address: —
  5. Account name: —
  6. Click Authentication Settings → enter Password and Shared Secret (PSK)
  7. Connect

Linux (NetworkManager)

  1. Install the L2TP plugin if needed: sudo apt install network-manager-l2tp-gnome
  2. Open Network Settings → VPN → Add → Layer 2 Tunneling Protocol (L2TP)
  3. Gateway: —
  4. Username / Password: as shown above
  5. Click IPsec Settings → enable, enter Pre-shared key
  6. Or via CLI: nmcli con add type vpn vpn-type l2tp con-name NFR-Lab ifname -- vpn.data "gateway=—,ipsec-enabled=yes,ipsec-psk=—,user=—" vpn.secrets "password=—"

iOS / Android

  1. iOS: Settings → General → VPN & Device Management → VPN → Add VPN Configuration → Type: L2TP
  2. Android: Settings → Network → VPN → Add VPN → Type: L2TP/IPSec PSK
  3. Server: —, Account / Password, Secret (PSK): as shown above
