■ Connection Instructions

Linux (strongSwan)

  1. Install strongSwan if needed: sudo apt install strongswan
  2. Add to /etc/ipsec.conf: 
    conn nfr-vpn
  keyexchange=ikev2
  right=—
  rightid=@nfr-vpn
  rightsubnet=0.0.0.0/0
  leftsourceip=%config
  authby=psk
  auto=start
  3. Add to /etc/ipsec.secrets: : PSK "—"
  4. Connect: sudo ipsec up nfr-vpn

Windows

  1. Open Settings → Network & Internet → VPN
  2. Click Add a VPN connection
  3. VPN provider: Windows (built-in)
  4. Connection name: NFR Lab
  5. Server name or address: —
  6. VPN type: IKEv2
  7. Type of sign-in info: Pre-shared key
  8. Pre-shared key: —
  9. Save, then click Connect

macOS

  1. Open System Settings → VPN
  2. Click Add VPN Configuration → IKEv2
  3. Display name: NFR Lab
  4. Server address: —
  5. Remote ID: nfr-vpn
  6. Authentication: None · click Authentication Settings → Shared Secret → paste PSK
  7. Connect

iOS

  1. Settings → General → VPN & Device Management → VPN → Add VPN Configuration
  2. Type: IKEv2
  3. Server: — · Remote ID: nfr-vpn
  4. Authentication: None · Secret: paste PSK
  5. Save, then toggle VPN on
